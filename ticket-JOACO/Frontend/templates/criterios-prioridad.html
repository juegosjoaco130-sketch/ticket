Criterios para seleccionar una prioridad

Volver a mis pedidos

¿Cómo seleccionar la prioridad?

La prioridad debe seleccionarse considerando el impacto que produce el incidente y la rapidez con la que necesita ser atendido.

Una prioridad mayor no significa que el problema sea más molesto, sino que afecta de forma más importante el funcionamiento de las actividades institucionales.

Prioridad fatal

Se utiliza cuando el incidente impide completamente realizar una actividad importante o afecta a varias personas, salones o servicios de la institución.

Ejemplos:

  • No hay conexión a Internet en toda la institución.
  • Un sistema institucional indispensable no funciona.
  • Existe una situación que puede comprometer la seguridad de las personas o de la información.
  • Varios equipos dejan de funcionar al mismo tiempo.

Prioridad alta

Se utiliza cuando el incidente afecta de manera importante una actividad y no existe una alternativa sencilla para continuar trabajando.

Ejemplos:

  • El sistema no registra los pedidos nuevos.
  • No es posible asignar repartidores durante el turno de entregas.
  • Un repartidor no puede acceder a la lista de sus pedidos asignados.
  • La conexión del local completo no funciona.

Prioridad media

Se utiliza cuando el problema dificulta el trabajo, pero la actividad puede continuar mediante otra alternativa.

Ejemplos:

  • Un equipo presenta fallas, pero existe otro disponible.
  • Una aplicación funciona de forma lenta.
  • Un periférico presenta problemas, pero no impide continuar la actividad.
  • El incidente afecta solamente a una persona y existe una solución temporal.

Prioridad baja

Se utiliza cuando el incidente tiene poco impacto, no interrumpe una actividad y puede resolverse sin urgencia.

Ejemplos:

  • Se solicita una configuración que no es urgente.
  • Existe un problema visual que no afecta el funcionamiento.
  • Se necesita revisar un equipo para una actividad futura.
  • Se realiza una consulta o solicitud de asistencia general.

Recomendación final

Antes de seleccionar la prioridad, pregúntate cuántas personas están afectadas, si la actividad puede continuar y si existe una solución alternativa.

Si tienes dudas entre dos prioridades, selecciona la que mejor represente el impacto real y describe claramente el problema en el pedido.
